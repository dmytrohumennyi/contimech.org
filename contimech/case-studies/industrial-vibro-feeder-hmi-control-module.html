Operator interface and control module for an industrial vibratory feeder

A local operator interface and embedded control module for a vibratory feeder that orients and feeds metal parts and fasteners into automated production equipment. Customer details are omitted.

Domain
Industrial automation
Interfaces
CAN, UART service port, local display and encoder
Status
Prepared for low-volume production, 2026
Services
2.2 Requirements · 2.3 Firmware · 2.1 Protocols

Task

Combine local control and operator interaction in one module. The module talks to peripheral controllers, drives and sensors over CAN, and gives service staff direct access to configuration, diagnostics and logs during commissioning and later support.

What we did

  • Wrote the requirements for operator access, CAN communication, diagnostics and logging, each with a verification method.
  • Implemented the menu and parameter firmware: navigation, parameter limits, local control buttons, encoder input.
  • Implemented CAN communication with the feeder peripherals and the I/O expansion.
  • Added fault detection with status visible from the local menu, plus event, fault and system-state logging for commissioning and troubleshooting.

Sample requirements

SYS-HMI-010The module shall provide local operator access to machine setup and operating parameters through the HMI.Verification: functional menu and parameter-access test
SYS-COM-020The module shall exchange defined control and status data with feeder peripherals over CAN.Verification: CAN conformance and machine integration test
SWR-DIA-030The firmware shall expose detected faults and system-state information through the local diagnostics function.Verification: injected fault and diagnostic display check
SWR-LOG-040The firmware shall record defined event, fault and system-state records for commissioning and troubleshooting.Verification: generated event and log retrieval check
