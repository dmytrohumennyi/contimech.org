CAN interface between an operator panel and a process controller

Excerpt from a self-contained interface control document for a CAN link between an operator panel (HMI) and the Control Board (CB) that owns the process. It is a public reference written to show our documentation standard. It contains no client material; identifiers, parameters and values are illustrative.

1Scope

This document specifies the communication interface between one Operator Panel (HMI) and its paired Control Board (CB) over a dedicated, galvanically isolated CAN segment. It is complete enough for both ends to be implemented by different teams and integrated without further agreement. Process control algorithms and HMI screen design are out of scope.

3Requirements

  1. ICD-GEN-010

    The CB shall be the sole authority for process state. The HMI shall display only state reported by the CB.

    IT

    Two owners of state diverge after any lost frame.

  2. ICD-GEN-030

    A safe stop shall be accepted from any HMI irrespective of its role.

    T

    The operator nearest the machine may not hold the session.

  3. ICD-NET-040

    Bulk configuration traffic shall not delay a command or a safety frame.

    AT

    Bus load from configuration must not degrade the safety path.

  4. ICD-E2E-020

    The CRC of each PDU shall include a per-message Data ID that is not transmitted.

    AT

    Detects frames delivered on the wrong identifier (masquerade).

  5. ICD-E2E-050

    A receiver shall treat a cyclic message whose alive counter is unchanged for 3 periods as lost.

    T

    A live task with a stale buffer looks alive without this check.

  6. ICD-SEC-060

    A node with absent or invalid keys shall enter the safe state and shall not fall back to unauthenticated operation.

    T

    A silent fallback would make authentication optional.

  7. ICD-APP-030

    The CB shall report the value actually applied, including clamping.

    T

    The panel must show process state, not the request.

  8. ICD-APP-050

    SAFE_STOP_REQ shall not be subject to session or mode checks.

    T

    Safety must not depend on configuration state.

  9. ICD-TIM-010

    The end-to-end safe-stop path shall actuate the output within 50 ms of the operator input.

    AT

    Derived from the machine risk assessment.

  10. ICD-TIM-050

    The CB shall send CMD_RESULT within 50 ms of a command.

    T

    Bounded feedback for the operator and for retries.

  11. ICD-FDIR-010

    The HMI shall indicate link loss and blank process values after 350 ms without a valid TM_STATUS.

    T

    Stale values must never look current.

  12. ICD-FDIR-030

    The CB shall release the configuration session after 1000 ms without a frame from the configuring HMI.

    T

    A dead panel must not block configuration.

  13. ICD-FDIR-040

    Loss of an HMI shall not by itself stop the process.

    T

    Availability: a panel failure is not a process failure.

  14. ICD-FDIR-050

    The CB shall enter the safe state after 3 failed bus-off recoveries within 10 s.

    T

    Bounded recovery instead of endless retry.

  15. ICD-FDIR-060

    The CB shall rate-limit responses to invalid authenticated traffic to 100 per second.

    T

    Invalid traffic must not starve the safety path.

  16. ICD-SEG-010

    A segmented transfer with no segment for 200 ms shall be abandoned and its partial data discarded.

    T

    Partial configuration is never applied.

Verification: T test · A analysis · I inspection · D demonstration

7Behaviour

8Timing

Frame time for an 8-byte standard frame with worst-case bit stuffing: 135 bits / 500 kbit/s = 0.27 ms. Worst-case safe-stop path:

StepWorst case
Input debounce5.00 ms
HMI input task period10.00 ms
Wait for a frame already on the bus0.27 ms
Transmission of SAFE_STOP_REQ0.27 ms
CB receive task period10.00 ms
CRC, counter, CMAC, freshness checks0.15 ms
Output actuation2.00 ms
Total, against 50 ms (ICD-TIM-010)27.7 ms

Nominal cyclic load per CB: 20 TM_PROCESS + 10 TM_STATUS frames per second × 135 bits ≈ 4.1 kbit/s, under 1 % of the bus.
