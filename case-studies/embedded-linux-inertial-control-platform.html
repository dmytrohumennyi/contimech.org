Linux compute layer inside a compact control electronics stack

The customer needed Linux-level services inside an existing compact electronics stack, without attaching an external single-board computer and without moving deterministic control loops into Linux. Images are softened; product details are omitted.

Platform
NXP i.MX93 (Cortex-A55 + Cortex-M33)
OS
Alpine Linux aarch64, NXP BSP kernel
Interfaces
CAN FD, GPIO, Ethernet, UART
Services
2.3 Firmware · 2.2 Requirements

Task

The new layer had to do the work of a gateway: exchange commands and status, coordinate peripherals, collect diagnostics. On top of that the customer wanted standard Linux capabilities: SSH service access, persistent logs, file-based configuration and maintainable updates. The board had to fit the existing circular geometry, stay cost-aware, and leave the real-time electronics unchanged.

What we did

  • Defined a circular compute board around the i.MX93 as one more layer of the stack, with only the memory and interfaces the product needs (1 GB LPDDR4X, 8 GB eMMC, CAN FD, GPIO, Ethernet, service UART).
  • Kept Linux supervisory. Sampling, timing-critical control and actuation stay on dedicated microcontrollers and never depend on Linux scheduling.
  • Built the I/O service on SocketCAN and libgpiod. ROS 2 / DDS integration stays optional instead of being coupled to the hardware layer.
  • Reduced the boot path: no U-Boot delay, device tree trimmed to the used hardware, console off the critical path, application service started before maintenance services. Design target: application-ready in 4 s or less from power-on.
  • Designed service access and updates: key-based SSH started after the application, service UART, versioned release bundle with integrity check, A/B system slots and rollback.

Why Linux and not another microcontroller

The core behaviour could run on an MCU. SSH, persistent logs, file-based configuration, package deployment and field debugging could not, at least not cleanly. A small application processor with a minimal Alpine userspace gave those features without a GPU, display stack or Wi-Fi module on the bill of materials.
